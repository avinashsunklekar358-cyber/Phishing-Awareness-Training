# PhishShield – Phishing Awareness & Prevention

An interactive cybersecurity awareness website built with **HTML, CSS, and JavaScript** for an internship project.

## Features
- Learn about phishing emails, fake websites, and social engineering
- Explore fictional examples of suspicious emails and login pages
- Interactive safety checklist with progress saved locally
- Five-question phishing awareness quiz with immediate feedback and score
- Incident-response guidance and links to official reporting resources
- Responsive design for desktop and mobile

## How to run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code **Live Server** extension and select **Open with Live Server**.

No build tools, server, database, or API keys are required. Google Fonts requires an internet connection; the site still works offline using fallback fonts.

## Files
- `index.html` – page structure and content
- `style.css` – styling and responsive layout
- `script.js` – checklist, navigation, and quiz logic

## Safety
All sample email addresses and URLs use reserved `.example` domains and are nonfunctional. This site never asks for or stores passwords. Checklist state is saved only in the local browser.
